# Barateiro Móveis — Landing Page

Landing page estática pronta para hospedagem na Vercel.

## Estrutura
- `index.html` — página principal
- `css/styles.css` — estilos
- `js/script.js` — interações
- `assets/` — imagens e vídeo
- `vercel.json` — configuração mínima para Vercel

## Publicação na Vercel
1. Crie um novo projeto na Vercel.
2. Importe este projeto/repositório ou use a Vercel CLI.
3. Não é necessário build command.
4. O arquivo `index.html` está na raiz do projeto.

## Observação importante
O formulário visual de nome, interesse e WhatsApp está presente na página, mas não envia dados para um banco/CRM por si só. Para captação real de leads, é necessário conectar o formulário a um destino (por exemplo, WhatsApp, Formspree, Supabase, webhook ou outro backend).

As fontes são carregadas pelo Google Fonts, portanto dependem de acesso à internet.
